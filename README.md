# Opekit Landing Page

Marketing site for **Opekit** — IT services, custom software, cloud, cybersecurity, and managed support for growing businesses.

**Website:** [www.opekit.com](https://www.opekit.com)

## Stack

- [Next.js](https://nextjs.org) 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Project structure

```
landing-page/       Next.js application
resources/          Design and content assets
Makefile            Convenience commands
```

## Getting started

The app lives in `landing-page/`. From the repository root:

```bash
make install  # install dependencies from the lockfile
make dev      # start the development server
make build    # create a production build
make run      # build and start the production server
make lint     # run ESLint
```

Or work directly in `landing-page/` with `npm install` and `npm run dev`.
